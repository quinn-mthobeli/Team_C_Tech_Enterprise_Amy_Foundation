# Amy Foundation Website Redesign

Welcome to the repository for the Amy Foundation website redesign project. This project aims to build a better, more modern, and highly functional web presence for the [Amy Foundation](https://amyfoundation.co.za/), supporting their mission to empower youth in our communities.

## 🎯 Project Scope

The primary objective of this project is to overhaul the existing Amy Foundation website. The scope includes:

*   **UI/UX Modernization:** Create a clean, engaging, and user-friendly interface that clearly communicates the foundation's impact and mission.
*   **Mobile Responsiveness:** Ensure the website functions seamlessly across all devices (mobile, tablet, and desktop).
*   **Performance Optimization:** Improve page load speeds and overall site performance for better SEO and user retention.
*   **Donation Flow Improvement:** Streamline the donation process to make it as easy and secure as possible for contributors.
*   **Content Management:** Structure the site so that foundation staff can easily update news, events, and programs.
*   **Accessibility:** Adhere to web accessibility standards (WCAG) to ensure the site is usable by everyone.
