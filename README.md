# Team C Tech Enterprise: Amy Foundation Website Redesign

## Project Scope
A modernized, fast, and responsive website for the Amy Foundation (https://amyfoundation.co.za/) to improve user experience, streamline donations, and showcase their programs.

## Folder Structure
- `src/main/` - Core source code (HTML, CSS, JS, or framework components)
- `tests/` - Unit and integration tests
- `public/` - Static files to be served directly
- `assets/` - Brand images, icons, and fonts
- `docs/` - Team documentation and sprint planning

## Getting Started
1. Clone this repository to your local machine.
2. Create a new branch for your feature: `git checkout -b feature-name`
3. Commit your changes and push for review.
